# Python 可读性排版

目标：**让代码容易扫读，排版一致，不追求刻意紧凑。** 仅处理当前任务涉及的 Python 代码。

## 约束

1. **缩进与行宽**：统一 4 空格缩进，目标行宽 100 字符；不使用 Tab、反斜杠续行或行尾空格。
2. **函数与调用**：简短且清晰时保持单行；需要换行时，每个参数或实参独占一行，保留尾逗号，右括号单独成行。多行签名、调用不要混用两种排版。
3. **容器与导入**：短列表、字典、集合保持单行；一旦换行，每个元素或键值对独占一行。导入按标准库、第三方、本项目分组；长导入逐项排列。
4. **逻辑空行**：顶层函数或类之间留两行，类方法之间留一行。函数内按「准备数据 → 校验 → 处理 → 返回」等逻辑阶段分段；互相独立的 `if ...: return/raise` 校验块之间通常留一行。不要在 `if/elif/else` 内部乱插空行，也不要连续留超过两行空行。
5. **条件与表达式**：长布尔条件用圆括号分行；复杂推导式、嵌套三元表达式、链式调用宁可展开成清楚的多行语句。不要写同一行的 `if ...: return ...`。
6. **限制修改范围**：排版调整不得改变行为；优先整理本次修改涉及的代码，不顺带格式化整个仓库。
