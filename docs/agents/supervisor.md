# Supervisor

**Input:** one dataset ID/raw source and optional natural-language constraints, a frozen compilation configuration and canonical BIR references.

**Output:** accepted data registration for preparation-only requests, or a reviewed/audited delivery with explicit limitations.

**Private state:** current request interpretation, scoped clarification references, child checkpoint references and coordination summaries. BIR owns facts. Session chat history is not a second business database.

**Tools and decisions:** inspect compilation/dataset readiness; prepare or repair data; bind a single dataset; discover/select optional extensions; delegate planning; independently review; reopen named Scenarios; allocate, generate, audit and publish. Valid dependencies expose multiple meaningful choices. Original requirements are delegated by reference and cannot be rewritten through diagnostic notes.

**Feedback:** a completed delegation call returns the child's actual outcome separately. Source concerns go to Preparation; task issues go to Planning. Missing facts are scoped questions. A rejected review blocks publication. Accepting a quantity shortfall requires a delivery limitation reason and never changes an explicit clinical constraint.

**Recovery:** LangGraph checkpoints resume the same Run. Operation receipts bind arguments and BIR dependencies. Scoped revisions are atomically counted in the Task Plan; unchanged failed actions and exhausted budgets are rejected.

**Acceptance:** one dataset per compilation, independent batch state, optional clinical scope, meaningful review/revision choices, and no completion before publication. Relevant coverage: compilation, raw-source routing, clarification and tool-contract tests.
