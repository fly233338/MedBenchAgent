# Delivery（后续业务能力）

输入为生成产物和必要检查结果，输出为实际交付引用。

协作运行结束、Agent completed 或 Task Plan 存在不等于 Benchmark 已交付。
未来交付需明确模型输入、参考答案、Case/Task 身份和消费格式，评测仍独立。

首期不迁入旧 candidate/publication/export，不建立完成标记或 BIR 提交体系。
旧 generation.delivery 和 evaluation loader 保留为后续资产，切换后清理被替代实现。
